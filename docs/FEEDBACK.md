# Feedback from real meetings

Notes from using Private Meeting Notes in real meetings. Each entry feeds the next build. Keep meeting content out of this
file: describe what went wrong, not what was said.

| Date | Build | Meeting (size, room, microphone) | What happened | What you expected |

| | | | | |

Useful details to note:

- Speakers: how many people, whether names were merged or split, and how much renaming and moving it needed.
- Transcript: words or names it got wrong repeatedly (these can go into a custom vocabulary in Build 3).
- Summary and action items: anything missing, wrong or invented.
- Timing: how long processing took (Settings shows the last run's timings) and whether the phone got hot.
- Recording: anything odd with the screen off, a phone call during recording, or an external microphone.
